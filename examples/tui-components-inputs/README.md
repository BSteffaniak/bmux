# TUI Components Inputs

Input and form examples for `bmux_tui_components`, including text input policy,
checkboxes, radio groups, select/dropdown controls, and form validation. The
examples keep text-edit and interaction state in the application while
components own measurement, cursor/selection projection, hit geometry, and
scoped painting from their authoritative layouts.

Run interactively:

```sh
cargo run -p bmux_tui_components_inputs
```
